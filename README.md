# 🚀 글로벌 대표 5대 가상자산 10년 시세 분석 & 실시간 모니터링 웹앱

Yahoo Finance(`yfinance`) API를 활용하여 대표 가상자산 5종(**비트코인, 이더리움, 솔라나, 리플, 도지코인**)의 10년 치 일봉 거래 데이터를 수집하고, 실시간 시세 반영, 기술적 지표(SMA, RSI), **5대 코인 상대 수익률 비교**, 그리고 **DecisionTreeRegressor 기반 AI 미래 시세 예측**을 제공하는 파이썬 Flask 기반 웹 대시보드입니다.

## ✨ 주요 기능

1. **상단 대표 5대 코인 원클릭 스위처 (Ticker Bar)**
   - 5개 코인의 실시간 가격 및 24시간 등락률을 상단 바에서 한눈에 확인
   - 원하는 코인 클릭 시 대시보드 전체(차트, 지표, 테마 컬러, 테이블, 통계)가 즉각 전환
   - 각 코인별 고유 브랜드 컬러 및 글래스모피즘 네온 테마 연동

2. **🤖 AI 머신러닝 미래 시세 예측 (DecisionTreeRegressor)**
   - **온디맨드 실행 (On-Demand Execution)**: 사용자가 `[미래 시세 예측 실행]` 버튼을 클릭했을 때만 모델 학습 및 검증이 수행되며 평상시에는 서버 부하 없이 대기
   - **전처리 (오늘 기준 데이터 분할 & 래그 피처)**:
     - **Feature**: 최근 5일간 가격 (`D-1, D-2, D-3, D-4, D-5`)
     - **Target**: 오늘의 가격 (`Close_t`)
     - **학습 세트 (Train)**: 3년 전 ~ 1년 전 일봉 데이터
     - **검증 세트 (Test)**: 1년 전 ~ 어제 일봉 데이터
   - **모델 및 성능 평가**:
     - `sklearn.tree.DecisionTreeRegressor` 활용
     - **목표 지표 달성**: 1개년 검증 세트 **MAPE 5.0% 미만** 달성 (BTC 기준 ~1.75%, 전 코인 3% 미만)
   - **예측 결과 시각화**:
     - 내일(D+1) 예상 시세, 등락폭 및 등락률, 원화 환산액
     - 성능 평가 카드 (MAPE, MAE, RMSE, 방향성 적중률)
     - D-1 ~ D-5 피처 중요도(Feature Importance) 분석 바
     - 최근 1개년 실제 가격 vs 모델 검증 가격 비교 차트 + 내일 예상 지점 표기

3. **Yahoo Finance 10년 거래데이터 연동 & 스마트 소수점 처리**
   - 각 코인별 10개년 동안의 일봉(OHLCV) 실시간 수집 및 서버 인메모리 캐싱(2분 만료)
   - 고가 코인(BTC, ETH, SOL) 2자리, 저가 코인(XRP, DOGE) 4자리 맞춤 소수점 표시

4. **핵심 시장 지표 (KPI Cards)**
   - **현재 가격**: 실시간 USD 가격 및 원화(KRW) 환산 금액
   - **24시간 변동폭 / 변동률**: 전일 종가 대비 등락폭 및 색상(Green/Red) 표시
   - **10년 최고가 / 최저가**: 역사적 전고점(ATH) 및 최저점 일자 표기
   - **10년 누적 수익률**: 수집 시작일 대비 총 수익률(%)
   - **24시간 거래대금**: 일일 거래대금 및 30일 평균 거래량
   - **RSI (14일)**: 과매수(70 이상) / 과매도(30 이하) 판별 및 실시간 게이지

5. **다양한 차트 제어 및 기술적 분석 (Chart.js)**
   - **기간 필터**: 1개월(1M), 6개월(6M), 1년(1Y), 3년(3Y), 5년(5Y), 10년 전체(ALL)
   - **차트 스타일**: 면적 차트(Area), 라인 차트(Line), 봉/고저 범위 차트(Bar)
   - **보조 지표**: 50일 이동평균선(SMA 50), 200일 이동평균선(SMA 200) On/Off
   - **스케일 옵션**: 로그 축(Logarithmic Scale) 토글 지원
   - **하단 서브 차트**: 매수/매도 거래량(Volume) 히스토그램 연동

6. **🔥 5대 코인 수익률 상대 비교 탭 (Multi-Coin Return Comparison)**
   - 동일 시점(0%)을 기준으로 5개 코인의 기간별 누적 수익률(%)을 한 차트에서 비교
   - 기간별(1M, 6M, 1Y, 3Y, 5Y, ALL) 수익률 리더보드 순위(1위~5위) 자동 산출

7. **최근 30일 데이터 테이블 & 코인별 CSV 다운로드**
   - 최근 30일 거래 내역(일자, 종가, 전일비, 시가, 고가, 저가, 거래량) 열람
   - 선택된 코인의 10년치 전체 데이터를 CSV 파일로 즉시 내보내기 (`{coin}_10y_data.csv`)

8. **🏛️ 거시경제 지표 연동 (KOSIS 국가통계포털 한국은행 금리 통계)**
   - **한국은행(기관코드: 301, 통계표: DT_121Y010)** 공식 OpenAPI 연동
   - 예금은행 고정 및 변동금리대출 비중(가계·주택담보·기업대출) 실시간 수집 및 대시보드 시각화
   - 사용자 원본 코드의 기능을 100% 유지한 독립 수집 모듈 제공 (`kosis_collector.py`)
   - 실행 시 현재 디렉토리에 **`kosis.xlsx` 엑셀 파일 자동 생성 및 웹 다운로드** 지원

## 🏃 실행 방법

### 1) 배치 파일로 원클릭 실행 (가장 간편)
`LAST_PJT` 폴더 안의 `run.bat` 파일을 더블 클릭하면 자동으로 서버가 실행됩니다.

### 2) 터미널에서 Flask 웹앱 실행
```bash
cd LAST_PJT
python app.py
```
실행 후 웹 브라우저에서 `http://127.0.0.1:5000` 으로 접속하세요. (5번째 탭 `[🏛️ 거시경제 KOSIS 금리 통계]`에서 데이터 및 엑셀 다운로드 확인 가능)

### 3) KOSIS 데이터 단독 수집 및 kosis.xlsx 생성 스크립트 실행
```bash
cd LAST_PJT
python kosis_collector.py
```
실행 시 원본 코드와 동일하게 `kosis.xlsx` 파일이 생성되고 터미널에 저장 위치와 DataFrame 결과가 출력됩니다.
